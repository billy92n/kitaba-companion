# Campaign launch procedure

Use the final 0.1.3 installer only after its production Windows workflow is green. On the installed app, restore/open Sully, confirm integrity, confirm World and Media sections, verify file-loaded KITABA_UPDATE payloads are raw-hidden by default, export a fresh GM_FULL, create a campaign `.kitaba` backup, close/reopen and confirm revision persistence. Only then start the dedicated game chat with the master project source and that fresh GM_FULL.
